Privacy policy

Last updated: 12 October 2026

english-followup is a personal automation tool operated by Ondřej Veverka (onrejveverka@gmail.com). It is used only by its author, with his own Google account.

What the app accesses

  • Gmail: creates draft e-mails (follow-ups for students). It does not read the inbox.
  • Google Docs and Google Sheets: reads and writes the author's own attendance, lesson-log and payment documents.
  • Google Drive (read-only): finds those documents.

How data is used

Data is used only to produce the lesson follow-ups and records described above. It is not sold, shared with third parties, or used for advertising. Text from lesson notes may be processed by an AI model (Anthropic's Claude) to write the follow-up; it is not used to train models by the author.

Storage

Google access tokens are stored on the author's own computer. No Google user data is stored on any server operated by the author.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
